Contexte

Les problèmes
à résoudre

⚡
Déploiements manuels Chaque mise en production est effectuée à la main — source constante d'erreurs humaines et de régressions.
📊
Absence de visibilité Aucun outil de suivi des performances. Impossible de détecter les problèmes avant qu'ils impactent les utilisateurs.
🔍
Pas de supervision Sans monitoring, il est impossible de savoir si l'application est disponible ou en état de dégradation.
⟶
Solution proposée

Infrastructure
DevOps complète

  • Déploiements automatisés et reproductibles
  • Conteneurisation avec Docker pour l'isolation
  • Pipeline CI/CD Jenkins intégré
  • Monitoring Prometheus des métriques
  • Dashboards Grafana en temps réel
Stack technologique

Les outils
du projet

🐧
CentOS
Système d'exploitation Linux enterprise. Stable, sécurisé, idéal pour les serveurs de production.
🐳
Docker
Conteneurisation des applications. Garantit la cohérence entre les environnements dev/prod.
⚙️
Compose
Orchestration multi-conteneurs. Déploiement de toute la stack en une seule commande.
🔥
Prometheus
Collecte et stockage des métriques. Système de monitoring time-series haute disponibilité.
📈
Grafana
Visualisation et dashboards interactifs. Transformation des données brutes en insights visuels.
🔄
Jenkins
Automatisation CI/CD. Pipeline de build, test et déploiement continu de l'application.
Vue globale

du système

🔄 Jenkins
🐳 Docker Compose

🔥 Prometheus

Jenkins déclenche les builds → Docker Compose orchestre les conteneurs
L'app expose ses métriques → Prometheus les collecte → Grafana les visualise
